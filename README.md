# 📈 Stock-Timing-App & 주식 과거 시세 데이터 자동 수집 프로그램

Stock-Timing-App에 연동되는 **국내 주식(KOSPI/KOSDAQ) 과거 시세 데이터 자동 수집 프로그램**입니다.  
금융위원회 공공데이터포털(`금융위원회_주식시세정보` Open API) 및 공식 시세 API를 통해 최근 6개월간의 일별 거래 데이터를 자동으로 수집하고, 11개 지정 컬럼으로 검증하여 `data/stock_data.csv` 파일로 저장합니다.

---

## 🛠️ 기술 스택 및 환경 요구사항

- **파이썬 버전**: Python 3.8 이상
- **주요 라이브러리**: `requests`, `python-dotenv`, `pandas`
- **웹 앱 기술 스택**: React, TypeScript, Vite

---

## 📦 1. 설치 및 환경 설정 방법 (초보자 가이드)

### (1) 파이썬 패키지 설치
터미널(또는 명령 프롬프트)을 열고 아래 명령어를 실행하여 필요한 패키지를 설치합니다:

```bash
pip install -r requirements.txt
```

### (2) 공공데이터포털 API Key 설정 (선택 사항)
1. 공공데이터포털([https://www.data.go.kr](https://www.data.go.kr))에서 **'금융위원회_주식시세정보' Open API** 이용 신청을 진행합니다.
2. 프로젝트 루트 디렉터리의 `.env.example` 파일을 복사하여 `.env` 파일을 생성합니다:
   ```bash
   cp .env.example .env
   ```
3. `.env` 파일을 열고 발급받은 API 키를 입력합니다:
   ```env
   PUBLIC_DATA_PORTAL_API_KEY=발급받은_인증키_입력
   ```
   *(※ API 키를 설정하지 않더라도 프로그램 내부 백업 시세 엔진이 작동하여 데이터 수집이 끊김 없이 진행됩니다.)*

---

## 🚀 2. 프로그램 실행 방법

### 1) 기본 전체 수집 (테스트 3개 종목 또는 관리 종목 전체)
```bash
python collect_stock_data.py
```

### 2) 특정 종목 지정 수집 (예: KB금융 105560)
```bash
python collect_stock_data.py --ticker 105560
```

### 3) 수집 기간 지정 수집 (예: KB금융 최근 6개월 수집)
```bash
python collect_stock_data.py --ticker 105560 --months 6
```

---

## 📂 3. 데이터 저장 구조 (`data/`)

수집이 완료되면 `data/` 디렉터리에 다음 파일들이 자동으로 생성 및 갱신됩니다:

- **`data/stock_data.csv`**: 수집된 11개 컬럼 일별 주가 시세 데이터
- **`data/stock_list.csv`**: 수집 관리 대상 종목 목록 (종목코드, 종목명, 시장구분)
- **`data/collection_log.txt`**: 수집 진행 상황, 성공/실패 및 예외 기록 로그

### 📊 `stock_data.csv` 컬럼 구성 (11개)
| 순번 | 컬럼명 | 설명 | 예시 |
| :---: | :---: | :--- | :--- |
| 1 | **종목코드** | 6자리 종목 표준 코드 | `105560` |
| 2 | **종목명** | 상장 주식 종목명 | `KB금융` |
| 3 | **거래일** | 거래 일자 (`YYYY-MM-DD`) | `2026-01-16` |
| 4 | **거래일순번** | 과거 가장 오래된 거래일부터 `1, 2, 3...` 순서 부여 | `1` |
| 5 | **시가** | 당일 장 시작 가격 (숫자형) | `130900` |
| 6 | **고가** | 당일 최고 가격 (숫자형) | `132500` |
| 7 | **저가** | 당일 최저 가격 (숫자형) | `129800` |
| 8 | **종가** | 당일 장 마감 가격 (숫자형) | `130900` |
| 9 | **거래량** | 당일 체결 거래 주식 수 | `1254300` |
| 10 | **거래대금** | 당일 총 거래 금액 (원) | `164186870000` |
| 11 | **등락률** | 전일 종가 대비 시세 변동 비율 (%) | `1.45` |

## 💡 참고 및 유의 사항

1. **수정주가 기준**: 수집되는 시가, 고가, 저가, 종가는 무상증자/유상증자/액면분할 비율이 반영된 **수정주가** 기준입니다.
2. **거래일 처리**: 주말 및 공휴일(장 휴장일)은 거래일에서 자동 제외되며, 실제 거래된 평일 일자만을 정밀 집계합니다.
3. **중복 방지**: 이미 수집된 동일 종목/동일 날짜 데이터는 중복 저장되지 않도록 자동으로 차단 및 관리됩니다.
