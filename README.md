# 주식 매매 타이밍 추천 앱 개발

## 주요 내용
- 주식거래액이 큰 대세주 Top 20 리스트업
- 이 중 관심있는 종목 선택하고 관리
- 관심종목에 대한 차트 분석
- 각 종목별 최근 6개월 종가를 그래프로 나타내고, 3일 평균치를 오버레이로 나타냄
- 최근 3개월 동안의 3일 평균치 최고값을 표시하고, 주가가 이보다 X1%, X2% 낮아지면 차트에 매도 추천 표시
- 최근 3개월 동안의 3일 평균치 최저값을 표시하고, 주가가 이보다 Y1%, Y2% 높아지면 차트에 매추 추천 표시
- 대세주 추천 항목 외 관심종목이 있으면 검색하여 추가 입력 기능 구현
- 데이터 검색 시간 단축과 정확성을 위해 Stockprice의 Cache 파일을 서버에 운영
- 배포 링크 : https://elegant-pudding-9c7939.netlify.app/
